# Дизайн интерфейса

Макет будущего JS-клиента и токены, из которых он собирается.

```
ui/design/
├── mockup/      8 экранов макета (.dc.html) и раскладка холста (canvas.json)
├── tokens.css   CSS-переменные: цвета, шрифты, шкала текста, радиусы, отступы, тени, движение
├── tokens.json  те же значения для кода (TS, генераторы)
└── motion.css   анимации и правило «уменьшить движение»; требует tokens.css
```

## Макет

Экраны сделаны на холсте Design (claude.ai, артефакт «expsched — интерфейс планировщика»). Файл `.dc.html` —
страница этого формата: разметка с подстановками `{{…}}`, `<sc-for>` / `<sc-if>` и класс `Component` в конце
файла, где лежат данные экрана и обработчики. Работающим он становится только на холсте; в обычном браузере это
неисполняемая заготовка. Для переноса файл читается как спецификация:

- **стили** — в атрибутах `style` у элементов; общие значения уже вынесены в `tokens.css`;
- **данные и поведение** — в `renderVals()`: какие поля нужны экрану, что меняется по клику, что считается;
- **анимации** — в `<helmet><style>` каждого файла; общие собраны в `motion.css`.

Числа на экранах взяты из прогонов `scenarios/` (urgent_failure, backfill, preemption) и из ожидаемых значений
тестов. Где данных пока нет, стоит заглушка в квадратных скобках.

| Экран | Файл | Что показывает | Что можно сделать | Нужно от API |
|---|---|---|---|---|

## Правила

- **Две поверхности.** Светлая (`--color-surface`) — для работы с данными; тёмный «чертёж»
  (`--color-blueprint` и сетка `--grid-blueprint`) — для структуры: граф, события, объяснения. Узкий шрифт
  `--font-tech` — только на чертеже.
- **Акцент один.** Лайм `--color-accent` — выбранное, лучшее значение, то, что идёт сейчас. Ошибки и
  предупреждения — смысловые цвета, не акцент.
- **Цвет не единственный носитель смысла.** У статуса всегда есть слово, у полосы Ганта — подпись; потери и
  недоступность различаются штриховкой, а не только оттенком.
- **Размеры.** Цель нажатия не меньше `--touch-min`. Главные кнопки — `--control-height`, скругление
  в половину высоты.
- **Ширина телефона.** Колонка разделов становится строкой сверху, карточки встают в один столбец, широкие
  диаграммы прокручиваются внутри своей рамки.
- **Движение.** Одна кривая `--ease`. Появление — каскад с шагом `--stagger`, наведение — подъём на 3 px,
  данные — плавное изменение размеров. Пульсирует только то, что выполняется. При «уменьшить движение» всё
  мгновенно.
