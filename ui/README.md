# UI

UI — отдельный клиент REST API. Он не импортирует `expsched` и не хранит своего состояния: всё берётся
из результата прогона и журнала, которые отдаёт API. Форматы описаны JSON Schema в `../schemas/`,
из них можно генерировать типы для любого клиента.

- `streamlit/` — интерфейс на Streamlit;
- `web/` — место для JS-приложения, если интерфейс на него перейдёт.

У каждой реализации свои зависимости и сборка; в `pyproject.toml` ядра они не попадают.
