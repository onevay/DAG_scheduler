# Интерфейс

Интерфейс — JS-клиент [REST API](../docs/api.md) в [`web/`](web/README.md): React, TypeScript, Vite. Вид — по
макету, токенам и анимациям из [`design/`](design/README.md). Клиент не импортирует `expsched` и не хранит
своего состояния на сервере: всё, что он показывает, берётся из результата и журнала прогона; черновик входа
живёт в `localStorage` браузера. Вход, результат и запись журнала описаны JSON Schema в `../schemas/`
(`problem`, `result`, `event`), типы клиента генерируются из `schemas/openapi.json`.

```bash
make web-install   # один раз: зависимости клиента, нужен Node.js 20
make run           # сборка клиента и API одним сервером на http://127.0.0.1:8000
```

Для разработки — `make api` и `make web-dev` в двух терминалах: клиент на http://127.0.0.1:5173 с горячей
перезагрузкой, запросы `/v1` уходят на API. Всё одним контейнером — `docker compose up --build`.

## Экраны

- **Обзор** — последние прогоны, метрики выбранного, загрузка узлов и матрица занятости по часам; новый сценарий
  из примера.
- **Сборка** — вход: пример из `scenarios/`, свой `problem.json` или пустой; граф задач, свойства задачи,
  ресурсы, зависимости; проверка входа с подсветкой задач с ошибками; все параметры политики (вытеснение,
  старение очереди, прогноз перепланирования, мягкая или строгая проверка). Выгрузка собранного входа.
- **Кластер** — карточки узлов с ресурсами, события узлов на шкале и списком, интервалы недоступности.
- **Прогон** — метрики, диаграмма Ганта с проигрыванием по времени (отказы затенены, потерянная работа
  заштрихована, резервы отмечены), лента журнала, таблица задач с попытками и главной причиной ожидания,
  перепланирования; выгрузка `result.json` и `events.jsonl`.
- **Объяснения** — разложение makespan по критической цепочке, шаги цепочки с причинами ожидания, простой
  по узлам и часам с фильтром причин, итог по кодам.
- **Сравнение** — прогоны всех реализованных политик на одном входе, капсулы по метрике, профиль-«цветок»;
  **what-if** — вмешательства (узел, чекпоинт, вытесняемость, приоритет, дедлайн, без отказов) и карточки
  с дельтами к исходному прогону.
- **Контейнеры** — заглушка: режимы emulate/shadow/replay ещё не реализованы.
- `/system` — живая дизайн-система: все компоненты во всех состояниях.
