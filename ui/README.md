# UI

UI — отдельный клиент REST API (`/v1/...`). Он не импортирует `expsched` и ничего не хранит сам:
всё берётся из `result.json` и журнала `events.jsonl`, которые отдаёт API.
Форматы описаны JSON Schema из `../schemas/`: из них можно генерировать типы для любого клиента.

Раскладка рассчитана на замену реализации без переделки остального репозитория:

- `streamlit/` — первая реализация (Streamlit + Plotly, этап Э10);
- `web/` — появится, если интерфейс перейдёт на JS-приложение; `streamlit/` при этом можно удалить целиком.

У каждой реализации свои зависимости и сборка, они не добавляются в `pyproject.toml` ядра.
