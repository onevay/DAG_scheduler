# UI

Интерфейс — клиент [REST API](../docs/api.md). Он не импортирует `expsched` и не хранит своего состояния:
всё, что он показывает, берётся из результата и журнала прогона. Форматы входа описаны JSON Schema в
`../schemas/`, из неё можно генерировать типы для любого клиента. Следующий клиент (JS) ляжет рядом, в `web/`.

## Streamlit

```bash
uv sync --extra api --extra ui
make api   # API на http://127.0.0.1:8000
make ui    # интерфейс на http://localhost:8501
```

Адрес API задаёт переменная `EXPSCHED_API` (по умолчанию `http://127.0.0.1:8000`).

Что есть:

- вход: пример из `scenarios/`, свой файл или пустой; выгрузка собранного входа;
- редакторы узлов, задач, задач, подаваемых во время прогона, и событий узлов; параметры политики;
- проверка входа и граф зависимостей с подсветкой задач с ошибками;
- прогон и сравнение политик: метрики, диаграмма Ганта (отказы узлов затенены, потерянная работа
  заштрихована), таблица задач с числом попыток и главной причиной ожидания, интервалы ожидания задачи;
- выгрузка `result.json` и `events.jsonl`.

Логика без Streamlit — сборка входа из таблиц, граф, подготовка результата, клиент API — лежит
в `streamlit/expsched_ui/` и проверяется тестами `tests/ui/`.
