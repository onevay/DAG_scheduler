# Демо на 10 минут

Сценарий показа: от мгновенной симуляции до прогона на контейнерах со сбоями и восстановлением. Нужен только
`make run`; Docker не обязателен (агенты fake).

| Минуты | Что показать | Что сказать |
|---|---|---|
| 0–2 | «Обзор» → пример `ml_hetero` → «Сборка» | DAG ML-платформы: данные, предобучение, дообучения, оценки. Проверка по ходу ввода, нижняя граница makespan до запуска. У задачи — тип, ресурсы, чекпоинты, закон ускорения |
| 2–3 | «Кластер» | Узлы разной скорости: a100 вдвое быстрее v100, cpu-1 без GPU |
| 3–5 | «Запустить» (heft) → «Сравнить политики» | HEFT ставит задачу туда, где она раньше закончится: 27 ч против 48 у priority_backfill, граница 25. cpsat находит то же, las — без знания длительностей |
| 5–6 | «Почему 27, а не 25?» | Критическая цепочка, причины ожидания каждой задачи, простой узлов |
| 6–9 | «Контейнеры» → «Запустить демо» | Два агента на этой машине, длительности заранее неизвестны (у задачи — только оценка), хаос убивает контейнеры и роняет узлы. Кольца с «≈» — ожидаемая работа и полоса до p80; уточнения оценки — в журнале попытки; «Убить контейнер» — вручную |
| 9–10 | Секция «Сбои», «План и факт», «Открыть прогон» → «Проиграть журнал» | Сколько задач восстановлено и с какой позиции, сколько работы сохранили чекпоинты; план против факта и причина по задаче; проигрывание тех же фактов даёт те же решения |

Если показ на своём кластере: `install-agent.sh` на машинах с GPU (см. [guide.md](guide.md)), узлы
примера — их id, режим shadow.

Скриншоты в README обновляет `make screenshots`.
