# Изменения

Раздел версии целиком становится заметками её выпуска на GitHub.

## [1.0.0] — 2026-10-29

Первый выпуск: планировщик вычислительных экспериментов — симуляция, прогон на настоящих контейнерах, объяснения.

### Вход и проверка
- `problem.json`: DAG задач с ресурсами (ядра, ОЗУ, GPU — все необязательны), приоритетами, дедлайнами,
  чекпоинтами, ретраями, вытесняемостью и ограничениями по меткам; кластер узлов со скоростью; события
  отказов, возвратов и подачи задач; политика и её параметры. JSON Schema в `schemas/`.
- Проверка входа с кодами E/W и подсказками, режимы lenient и strict, нижняя граница makespan и критический
  путь до запуска.

### Планирование
- Событийный движок с проверкой инвариантов каждого расписания.
- Политики: `fifo`, `fifo_skip`, `priority`, `priority_backfill` (резервы, вытеснение по классу, старение),
  `heft` и `peft` (узлы разной скорости, раннее окончание), `las` (Tiresias, без длительностей), `cpsat`
  (OR-Tools, по желанию осторожный — по квантилю 0,8).
- Модель длительности: работа в единицах эталонного узла, закон ускорения по числу CPU/GPU (Амдал, степенной),
  неизвестная длительность — логнормальная оценка (своя, по истории прогонов, по задачам того же типа,
  умолчание типа), уточнение по ходу из прогресса задачи.
- Перепланирование по событиям, what-if, сравнение политик, объяснения: разложение makespan, причины ожиданий,
  простой по узлам.

### Прогон на агентах
- Агент на машине с контейнерами: Docker, Podman, gravesentinel (снимки CRIU) или fake без контейнеров;
  журнал состояния с подхватом после перезапуска и уплотнением, лимиты из ресурсов задачи, разрешённые образы,
  потребление и журналы контейнеров, служба systemd.
- Режимы emulate, shadow (план рядом с фактом и причины расхождений) и replay (те же решения на тех же
  фактах); несколько машин, отказ агента — отказ его узлов.
- Агенты на машине сервера одной кнопкой; токен для них сервер придумывает сам.
- «Убить контейнер» и хаос (`chaos`: сбои контейнеров и узлов по seed), лента и сводка сбоев, демо одной
  кнопкой на примере `chaos_demo`.

### Клиент
- Веб-клиент на React: обзор, сборка DAG на холсте, кластер, прогон с диаграммой Ганта и проигрыванием,
  объяснения, сравнение и what-if, контейнеры. Русский интерфейс, тёмная тема, узкий экран, доступность (axe).

### Эксплуатация
- Один сервер для API и клиента, образ Docker (`compose.yaml`), пределы входа и прогонов, аудит зависимостей.
- Выпуск по тегу `v*`: wheel и sdist, образы сервера и встроенной нагрузки в GHCR, `scripts/install-agent.sh`.
